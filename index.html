ค้นหาเครื่องมือ หรือวางอะไรก็ได้

วาง JWT, stack trace, JSON, SQL ใน Java, Secret YAML, timestamp, เลขบัตร หรือ SQLCODE แล้วจะเปิดเครื่องมือที่ใช่พร้อมกรอกให้ หรือลากไฟล์มาวางที่ไหนก็ได้ ทุกอย่างทำงานในเบราว์เซอร์ ไม่ส่งข้อมูลออกไปไหน

ลอง:

เคล็ดลับที่ช่วยให้ใช้เร็วขึ้น

  • CtrlKค้นหาเครื่องมือหรือวางข้อความได้จากทุกหน้า แถบล่างบอกว่าแต่ละตัวทำอะไรก่อนเปิด
  • กดดาวข้างชื่อเครื่องมือในเมนูซ้าย เพื่อปักไว้ที่รายการโปรดด้านบนสุด
  • ลากไฟล์ (JSON, YAML, Dockerfile, log) มาวางที่ไหนก็ได้ ระบบเปิดในเครื่องมือที่ใช่ให้
  • ปุ่มลิงก์มุมขวาบน คัดลอกลิงก์ของเครื่องมือพร้อมข้อมูลที่กรอก ส่งให้เพื่อนเปิดเห็นแบบเดียวกัน (ไม่รวม token / secret)
  • ข้อความที่กรอกถูกจำไว้ในเบราว์เซอร์นี้ ปิดหรือล้างได้ที่ปุ่มตั้งค่า

พิมพ์ SQLCODE หรือ SQLSTATE ที่เจอใน log (เช่น -803, 23505, 4499) เพื่อดูสาเหตุและวิธีแก้ · ถ้ามีทั้ง stack trace ใช้หน้า Stack Trace Analyzer จะหาให้อัตโนมัติ

วาง stack trace จาก log ทั้งก้อน (รวม Caused by) ระบบจะหาต้นเหตุ บรรทัดที่เป็นโค้ดของเรา และดึงวิธีแก้จากหน้า Java Exceptions / DB2 Error Codes มาให้

exception ที่เจอบ่อยใน Java / Quarkus / Hibernate พร้อมสาเหตุและวิธีแก้ · ค้นด้วยชื่อ class หรือข้อความใน error ได้ เช่น no Session, acquisition timeout

เข้าใจสิ่งที่เกิดขึ้นเบื้องหลัง: โค้ดถูก compile และรันยังไง หน่วยความจำของ JVM การสร้าง annotation เอง และ transaction ใน Quarkus

NgRx คือ Redux สำหรับ Angular · กด dispatch แล้วดู action วิ่งผ่าน Reducer, Effect, Store และ Selector ทีละขั้นพร้อม state จริงในแต่ละจังหวะ

อ่านไฟล์ทีละบรรทัด: manifest, mount ไฟล์, Dockerfile, compose, Helm

request หนึ่งครั้งวิ่งผ่านหลายชั้นก่อนถึงแอป แต่ละชั้นพังได้ด้วยอาการต่างกัน · กดแต่ละกล่องเพื่อดูหน้าที่และอาการที่เจอบ่อย
