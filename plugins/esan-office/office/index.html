ทีม agent

มี 2 แบบ: agent ประจำออฟฟิศที่กดเพิ่มเอง สั่งงาน ตั้งคำสั่งประจำตัว และกดอนุญาตได้จากหน้านี้ กับ session ที่คุณเปิดเองใน terminal หรือแอป ซึ่งดูได้อย่างเดียว แตะที่ตัว agent หรือกดปุ่มที่การ์ดเพื่อเปิดแผงของตัวนั้น

    วิธีใช้งาน

    กดเพื่อเปิดดู

    สั่งงาน agent ประจำออฟฟิศครั้งแรก ทำตามนี้ทีละขั้น

    1. สร้าง agent

      กดปุ่ม เพิ่ม agent ด้านบน เลือกหน้าที่สำเร็จรูป เช่น Frontend หรือ QA ตั้งชื่อ แล้วใส่โฟลเดอร์ทำงานเป็น path เต็ม เช่น D:/work/shop-ui เลือกเครื่องมือที่ให้ใช้ได้เลยโดยไม่ต้องถาม กับโมเดล (Haiku ประหยัดที่สุด) แล้วกด สร้าง agent ตัวใหม่จะย่างเข้าประตูมา

    2. ส่งงาน

      แตะตัว agent ในห้อง หรือกดปุ่ม สั่งงาน ที่การ์ด พิมพ์งานที่ต้องการ แล้วกด ส่งงาน (หรือ Ctrl+Enter) agent จะย่างไปนั่งโต๊ะ กล่องเหนือหัวบอกว่ากำลังใช้เครื่องมืออะไร ถ้ากำลังทำงานอื่นอยู่ งานใหม่จะต่อคิวไว้

    3. กดอนุญาตเมื่อถูกถาม

      ถ้า agent จะใช้เครื่องมือนอกรายการ เช่น เขียนไฟล์หรือรันคำสั่ง จะมีปุ่มสีเหลือง มีคำขออนุญาต ขึ้นด้านบน กดเปิดแล้วดู path หรือคำสั่งเต็มก่อน แล้วค่อยกดอนุญาตหรือไม่อนุญาต ถ้าไม่มีใครกดภายใน 4 นาทีจะปฏิเสธเอง

    4. ดูผลงาน

      ทำเสร็จแล้ว agent จะลุกไปพักที่มุมพัก เปิดแผงของตัวนั้นเพื่อดูคำตอบล่าสุด ลำดับเหตุการณ์ ค่าใช้จ่ายโดยประมาณ และ context ที่เหลือ สั่งงานต่อได้เลย agent จำบทสนทนาเดิม

    • session ที่เปิดเอง

      เปิด Claude Code ใน terminal หรือแอปตามปกติ agent จะย่างเข้ามาเอง พิมพ์งานในหน้าต่าง Claude Code แล้วดูความคืบหน้าในออฟฟิศได้ ถ้าขึ้นสีเหลืองให้กดอนุญาตในหน้าต่าง Claude Code

      ดูได้อย่างเดียว
    • หยุด เอาออก ลบ

      ปุ่ม หยุด ที่การ์ดตัดงานที่ทำอยู่และล้างคิว ปุ่ม เอาออก ที่การ์ดของ session ที่เปิดเองใช้กับตัวที่ปิดหน้าต่างไปแล้วแต่ยังค้างในห้อง ทั้งสองปุ่มต้องกด 2 ครั้งเพื่อยืนยัน เริ่มบทสนทนาใหม่ ให้ agent ลืมเรื่องเก่า ลบ agent ต้องกด 2 ครั้ง

      เริ่มใหม่กับลบอยู่ใน "ตั้งค่า agent ตัวนี้"
    • แก้คำสั่งประจำตัว

      เปิด "ตั้งค่า agent ตัวนี้" แก้หน้าที่ โฟลเดอร์ คำสั่งประจำตัว เครื่องมือ หรือโมเดล แล้วกดบันทึก มีผลกับงานถัดไป

      ไม่ต้องสร้างใหม่
    • ประหยัด token

      งานง่ายใช้ Haiku ให้เครื่องมือเท่าที่จำเป็น และกดเริ่มบทสนทนาใหม่เมื่อแถบ context ใกล้หมด ทำพร้อมกันได้ครั้งละ 3 ตัว ที่เหลือจะรอคิว

      ทุกงานที่สั่งกิน token จริง
    • ถามด่วน

      พิมพ์คำถามง่าย ๆ ในช่อง ถามด่วน ใต้ปุ่มเพิ่ม agent ระบบใช้ agent ชื่อ Easy Research (Haiku ค้นเว็บได้ ไม่แก้ไฟล์) และเริ่มบทสนทนาใหม่ทุกคำถาม หรือเลือกหน้าที่ Easy Research ตอนเพิ่ม agent ก็ได้

      กิน token แต่น้อย
    • แกล้ง agent

      แตะตัว agent ที่กำลังเดินเล่นหรือพักอยู่ จะมีเมนูเล็ก ๆ ให้เลือก ขัดขา จั๊กจี้ สาดน้ำ หรือหลอกผี เป็นแค่ภาพในหน้านี้ ไม่กระทบงาน ตัวที่นั่งทำงานอยู่แกล้งไม่ได้

      ไม่ส่งอะไรไปที่ bridge

    สัญลักษณ์ในออฟฟิศ

    กดเพื่อเปิดดู
    • agent ประจำออฟฟิศ

      กดเพิ่ม agent แล้วเลือกโฟลเดอร์กับหน้าที่ พิมพ์งานส่งได้เลย ทำงานพร้อมกันได้ครั้งละ 3 ตัว ที่เหลือต่อคิว ถ้าต้องใช้เครื่องมือนอกรายการจะขึ้นปุ่มอนุญาตให้กด ทุกงานที่สั่งกิน token จริง

      claude -p ในโฟลเดอร์ของ agent
    • โต๊ะคอม 12 ตัว

      พอคุณพิมพ์ prompt agent จะย่างมานั่งพิมพ์ จอสว่างและมีโค้ดวิ่ง ตอบเสร็จก็ลุกไปพัก ถ้าโต๊ะเต็มจะยืนทำงานในมุมพักแทน

      UserPromptSubmit → Stop
    • กล่องข้อความเหนือหัว

      ชื่อเครื่องมือที่ agent กำลังใช้ ถ้าขอบเป็นสีเหลือง แปลว่ารอให้คุณกดอนุญาต (agent ประจำออฟฟิศกดในหน้านี้ได้ session ที่เปิดเองกดใน Claude Code)

      PreToolUse, PermissionRequest
    • แถบบนหัว

      context ที่เหลือ ถ้ายังไม่ได้ตั้ง statusline จะเป็นค่าประมาณจากไฟล์ transcript (มีเครื่องหมาย ≈ ข้างหน้า)

      transcript หรือ statusline
    • ประตู

      เปิด session ใหม่ agent จะย่างเข้าประตูมา ปิด session ก็ย่างกลับบ้าน subagent ใส่หมวกฟ้าเข้ามาช่วยงานแล้วออกไป

      SessionStart, SubagentStart/Stop, SessionEnd
    • มุมพักแบบอีสาน

      ร้านส้มตำกับกระติบข้าวเหนียว โอ่งน้ำ เสื่อกับหมอนขวาน ตู้อาเขต ลู่วิ่ง เครื่องยกน้ำหนัก โต๊ะโป๊กเกอร์ และสนามมวย agent ที่ว่างจะเลือกไปเอง

      สถานะ: ว่าง

    ข้อมูลทั้งหมดอยู่ในเครื่องนี้เท่านั้น วิธีติดตั้ง การตั้ง statusline ให้ได้ context กับโควตาแบบตัวเลขจริง และการดูจากมือถือ อยู่ใน README ของ plugin
